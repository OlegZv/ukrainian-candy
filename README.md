# Ukrainian Candy Showcase

I brought a bunch of Ukrainian candy to the office. With a diverse crowd I thought it would be good to share the description, ingredients, and nutritional info.

## Sources

Some images, ingredients, and nutritional info are from [MarvelFoods](https://www.marvelfoods.com/) and [Novus](https://novus.zakaz.ua/en) websites.

*The ingredients were cross-referenced with the actual label at the store for accuracy.*

> **Kudos to my partner Jessica for finding the sources!**

## Files
- `index.html` — page layout and content shell
- `styles.css` — responsive card styling
- `script.js` — candy data and live search
- `imgs/` — candy images used by the page

## Notes
- The page is intentionally simple and works with plain HTML, CSS, and vanilla JavaScript.
- Search will filter by candy name and ingredients text.
- Ingredients and nutrition details can be updated in `script.js` as needed.
